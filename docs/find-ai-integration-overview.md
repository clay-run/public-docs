# Find AI integration (deprecated)

**Find AI (UseFind.ai) is a deprecated third-party integration.** For new searches, use Clay's built-in **Find leads** and select **People** or **Companies**.

## Search with Clay's built-in tools

- From the left sidebar or the home page's **Find leads** card, choose **People** or **Companies**.
- Inside a workbook, click **+ Add** and choose **Find people** or **Find companies**.
- In a Workflow, add a **Find people** or **Find companies** node.

Start with filters, or describe your criteria in the search assistant and review the search it builds. See [Finding companies and people in Clay](finding-companies-and-people-in-clay.md#where-to-start-a-search) for navigation and [Find with query](finding-companies-and-people-in-clay.md#find-with-filters-and-find-with-query) for advanced query mode.

## Existing Find AI sources

Existing sources named **Find people with Find AI (beta)** or **Find companies with Find AI (beta)** refer to the separate integration, not Clay's built-in search. Their configured cost estimate is 1 credit per result; check the displayed estimate before running an existing source.

Clay's `select from people ...` and `select from companies ...` query syntax belongs in **Find with query**, when available in the built-in search. Do not paste that syntax into Find AI.
